# API Documentation

Base URL: `http://localhost:3000`

All responses use JSON. Student fields are `name`, `email`, and `course`.

## 1. Create a student

- **Method:** `POST`
- **URL:** `/api/students`
- **Body:**
```json
{
  "name": "Asha Rao",
  "email": "asha@example.com",
  "course": "BCA"
}
```
- **Success:** `201 Created`
- Duplicate email returns `409 Conflict`; invalid or missing fields return `400 Bad Request`.

## 2. Get all students

- **Method:** `GET`
- **URL:** `/api/students`
- **Success:** `200 OK`

## 3. Get one student

- **Method:** `GET`
- **URL:** `/api/students/1`
- **Success:** `200 OK`
- Missing student returns `404 Not Found`; invalid ID returns `400 Bad Request`.

## 4. Update a student

- **Method:** `PUT`
- **URL:** `/api/students/1`
- Send one or more fields:
```json
{
  "course": "BCA Cybersecurity"
}
```
- **Success:** `200 OK`
- Missing student returns `404`; duplicate email returns `409`; invalid input returns `400`.

## 5. Delete a student

- **Method:** `DELETE`
- **URL:** `/api/students/1`
- **Success:** `200 OK`
- Missing student returns `404`; invalid ID returns `400`.

## Example success response

```json
{
  "success": true,
  "message": "Student created successfully.",
  "data": {
    "id": 1,
    "name": "Asha Rao",
    "email": "asha@example.com",
    "course": "BCA",
    "created_at": "2026-10-08 10:00:00"
  }
}
```

The `created_at` timestamp is generated by SQLite and will reflect the database server's time.

## Testing with Postman

1. Start the server using `npm start`.
2. Create a request and select the method shown above.
3. Enter the full URL.
4. For POST and PUT, choose **Body → raw → JSON** and enter the example JSON.
5. Click **Send** and check the status code and response.
6. Test validation by leaving out `name`, using an invalid email, or creating the same email twice.
